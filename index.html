使用提示
从任意组件开始

挑选左侧预设，放入当前手机页面；右侧可调整文字、颜色、动画和按钮行为。

设计真实操作路径

新建页面并给按钮设置“切换页面”，把首页、详情和完成页连成一条可预览的流程。页面列表右键可设置主导航页或子页面；点击底部导航页后，可在右侧更换图标。

直接在画布上操作

点击选中，拖动调整顺序，右键打开复制、粘贴和移动菜单。预览时可点击按钮体验交互。

带走你的作品

“保存”会下载可继续编辑的项目文件；“导出网页”会生成可独立运行的 HTML。

HTML 与 CSS

组件是页面内容，右侧属性决定外观。选中元素时，右下角会显示对应的 CSS 样式。
